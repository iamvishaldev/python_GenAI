# python_GenAI

Personal practice repo for the Udemy course [Full Stack AI with Python](https://www.udemy.com/course/full-stack-ai-with-python/) (Hitesh Choudhary) — Python fundamentals through AI/agentic integration, building toward a remote AI job.

## Resuming after a break

1. Open **`Course_Tracker.xlsx`** — `Course Tracker` sheet shows exactly which topic you're on and what needs revision; `Projects` sheet tracks portfolio project status.
2. Jump straight into the matching numbered folder below — no need to re-read old code first, the tracker's `Notes` column has the "where I left off" context.
3. Update the tracker's Status/Last Revised columns before you stop for the day, so future-you doesn't have to re-diagnose progress.

Topics beyond `11_concurrency_parallelism` (API integration, LLM/GenAI integration, agentic AI, pipelines) aren't in the repo yet — add numbered folders (`12_...`, `13_...`) as you reach them, and update `Course_Tracker.xlsx` to match.
